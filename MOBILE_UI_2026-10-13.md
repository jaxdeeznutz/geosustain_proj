# Header and boundary mapper corrections

- Shared dashboard headers now use solid GeoSustain green (#08733F), with white branding and a 12 px gap before the next section. Mapping headers use the same green, with 16 px content padding beneath them.
- GPS and drawn boundaries share the instruction-card design, mint area/vertex summary, map layer selector, white map controls, numbered white-bordered vertices, and larger green/outlined action buttons. GPS retains its recording, pause, resume, accuracy, and review behavior.
- Polygon farm fields are grouped in a white card. Banner artwork is softened for legibility. Home uses four quick-action cards at normal phone text sizes, with a two-column fallback for narrower screens or enlarged text.
- Farm-detail errors now appear above the map so a failed history request remains visible.

The earlier implementation used an illustrated header and a separate GPS layout; those were the main causes of the inconsistency. The supplied images remain the visual reference, but the artwork and live data are not identical copies of the mockups.
