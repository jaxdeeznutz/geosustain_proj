# GeoSustain Development Guide

When working on GeoSustain:

- Follow AGENTS.md and knowledge.md.
- Use Flutter for frontend development.
- Use FastAPI for backend development.
- Use backend/fastapi_app.py as the backend entry point.
- Keep API keys and credentials private.
- Never commit backend/.env.
- Preserve existing functionality.
- Avoid changing the machine-learning model unless required.
- Test changes before committing.
- Use the Sub-branch-demo branch for this activity.
