# Independent raster arithmetic references

The expected values below are derived analytically from unit squares, triangle areas and cell values. They are not generated by the implementation under test. Tests live in `backend/tests/test_spatial_analysis.py`.

| Case | Geometry / observations | Independent expected result |
| --- | --- | --- |
| Full 2 x 2 | Four equal unit cells: 1, 2, 3, 4 | min 1, max 4; mean and median 2.5; population variance 1.25; standard deviation sqrt(1.25); 4 valid/intersecting cells; 100% valid area. |
| Partial triangle | x >= 0, y >= 0, x+y <= 2. Intersections: 0.5 area at value 1, 1 area at value 3, 0.5 area missing | valid area 1.5 of 2 = 75%; mean (0.5+3)/1.5 = 7/3; weighted median 3; variance 8/9; 2 valid of 3 intersecting cells. |
| Concave L | Three unit squares; the excluded upper-right square has value 999. Valid values 1 and 3; third square missing | Excluded 999 contributes nothing; mean/median 2; population standard deviation 1; valid coverage 2/3. |
| Tiny polygon | Triangle entirely inside one coarse source cell at value zero | One valid cell; min/max/mean/median 0; standard deviation 0; 100% valid area. No fabricated finer detail. |
| Constant | Every valid intersection has value 6 | Every summary is 6 except standard deviation 0; one-color legend, no division by zero. |
| Partial grid extent | Grid covers exactly half the parcel | Grid-extent fraction 0.5 and valid coverage no more than 0.5. Outside grid is unevaluated. |
| All missing | Null/nonfinite/sentinel/invalid-mask observations | No valid statistics; unavailable layer; zero valid coverage, never valid zero estimates. |

Additional tests cover reversed/concave rings, collinear points, invalid transforms, projected-coordinate numerical precision, valid zero, invalid scalar types, cache immutability and request/pixel budgets. Offline provider tests serialize all seven actual Earth Engine expressions and exercise bounded REST/NPY mask decoding without claiming live provider success.

Vector QA renders are in `vector-qa/`: NDVI visibly preserves the L-shaped concavity and gray holes; constant pH remains one color. Actual Flutter maps and report PDFs remain separate client/manual gates.
