# GeoSustain Knowledge

GeoSustain is an AI-driven geospatial decision-support system used for agricultural land analysis in Panabo City.

## Main Users

- Farmer
- Agricultural Planning Analyst
- Super Administrator

## Main Technologies

Frontend:
- Flutter
- Dart

Backend:
- FastAPI
- Python

Database:
- PostgreSQL / Supabase

Environmental Data:
- Google Earth Engine
- OpenWeather
- Open-Meteo
- NASA POWER

## Main Functions

GeoSustain supports:

- Farm boundary management
- Polygon-based land analysis
- Environmental data collection
- Seasonal analysis
- Crop suitability analysis
- Explainable AI
- Map visualization
- Farmer submissions
- Analyst verification
- Printable reports
